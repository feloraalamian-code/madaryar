# مادر‌یار (MadarYar)

مادر‌یار یک وب‌اپلیکیشن ساده برای کمک به مادران در مدیریت بخشی از
کارهای روزمره خانه و پیگیری اطلاعات مهم مربوط به کودک است.

## هدف پروژه

هدف مادر‌یار کاهش بخشی از بار ذهنی مادر و فراهم کردن ابزارها و
اطلاعات کاربردی در یک محیط ساده و قابل استفاده است.

## MVP

نسخه MVP شامل دو بخش اصلی است:

- خانه
- کودک

همچنین یک بخش کوچک با عنوان «برای خودم» برای محتوای حمایتی مادر وجود دارد.

## بخش خانه

- مدیریت کارهای روزانه
- مدیریت موجودی اقلام ضروری خانه
- یادآورهای انگیزشی

## بخش کودک

- ثبت قد و وزن و مشاهده روند رشد
- پیگیری واکسن‌ها
- اطلاعات عمومی درباره نگرانی‌های رایج
- ثبت آلرژی‌های غذایی
- اطلاعات عمومی درباره آلرژن‌های غذایی
- محتوای تغذیه و دستورهای ساده

## وضعیت پروژه

این پروژه در مرحله توسعه MVP قرار دارد.

## محدوده پزشکی

مادر‌یار یک محصول پزشکی یا تشخیصی نیست و اطلاعات سلامت آن
صرفاً جنبه عمومی و آموزشی دارد.
