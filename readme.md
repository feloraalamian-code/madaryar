# مادریار (MadarYar)

مادریار یک وب‌اپلیکیشن برای خودِ مادر است.

---

## چرا مادریار؟

بیشتر اپ‌های ایرانی مادر و کودک، روی کودک تمرکز می‌کنند.
مادریار یک نگاه متفاوت دارد:

«تو، مادر، هم مهمی.»

---

## تفاوت مادریار با بقیه

| بقیه اپ‌ها | مادریار |
|------------|----------|
| تمرکز روی کودک | تمرکز روی مادر |
| پزشکی | حمایتی و روانی |
| متخصص-مراجع | همراه-دوست |
| حل مشکل کودک | کاهش بار ذهنی مادر |

---

## MVP

مادریار 3 ماژول اصلی دارد:

**1. برای خودم**
- جعبه هدیه
- چالش روزانه
- تمرین تنفس
- آرشیو محتوا

**2. نظم خانه**
- چک‌لیست روزانه
- چک‌لیست هفتگی
- چک‌لیست ماهانه
- راهنمای تمیزی
- امروز چی بپزم؟

**3. کودک**
- قد و وزن
- واکسن‌ها
- تربیت و رشد

## محدوده پزشکی

مادریار یک محصول پزشکی یا تشخیصی نیست و اطلاعات سلامت آن صرفاً جنبه عمومی و آموزشی دارد.

---

## Stack فنی

- Frontend: Next.js 16 + TypeScript + Tailwind CSS
- Backend: Next.js API Routes
- Database: Supabase (PostgreSQL + Auth)
- فونت: Vazirmatn
- Android (بعداً): Capacitor

---

## شروع کار

دستورات زیر را در ترمینال اجرا کن:

اول: npm install

بعد: npm run dev

بعد باز کن: http://localhost:3000

---

## ساختار پروژه

ساختار پوشه‌های اصلی:

src/app برای صفحات

src/app/(app)/self-care برای بخش «برای خودم»

src/app/(app)/home برای بخش «نظم خانه»

src/app/(app)/child برای بخش «کودک»

src/components برای کامپوننت‌ها

src/lib برای کدهای کمکی

src/content برای محتوای ثابت (JSON)

src/types برای تعریف انواع
